# Synth Agent SSH

MCP server for repo-scoped work on a paired PC over SSH, built on the cross-pc-ssh helper

Seeded from **synthet-code-framework**. Agent scaffolding lives in `.claude/`, `.cursor/`,
`.agents/`, `.codex/`, `.agent/`, and `.agent-memory/`. Start with [`CLAUDE.md`](CLAUDE.md)
and [`AGENTS.md`](AGENTS.md); Codex setup is documented in [`.codex/README.md`](.codex/README.md).

Fill in build/test/lint commands in `CLAUDE.md` + `AGENTS.md`, choose a backlog provider,
and fill optional provider IDs (for example, GitHub Projects IDs) only when that provider needs them
(search for `TODO(` markers).
